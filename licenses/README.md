## PCGL について

PHI のグラフィックス(キャラクター/オブジェクト/マップパーツ/アイコン等)の
**統一利用ライセンス**。phi-client-web のように新クライアント/Web で当該グラフィックスを
使用・配布する場合、PCGL に従い「使用グラフィックスが PCGL 下にある」旨の明記が必要
(ルート `README.md` のライセンス節および本ファイルがその明記)。

PCGL 文書自体は自由にコピー・頒布可、**改変不可**。グラフィックス資産を同梱配布する
成果物には、本ライセンス全文(`PCGL.sjis.txt` または `PCGL.utf8.txt`)を添付すること。
