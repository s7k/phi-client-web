# 管理者マニュアル

管理画面(キャラグラ/マップチップのアップロード・管理、キャラ名紐付け、ユーザ管理)の操作手順と禁止事項。

## 1. 管理者になる

- **初回アカウント = 自動的に管理者**。アカウントが1件も無い状態で最初に作成したアカウントは管理者になる(Web 経由で初期管理者を用意するため)。2件目以降は一般アカウント。
- 以後の管理者付与/剥奪は、管理者が「管理画面 → ユーザ管理」で行う。
- CLI でも作成/付与可能: `python -m app.admin_cli create-account <id> <pw> --admin` / `grant <id>`。

## 2. 管理画面を開く

ログイン → キャラクター選択画面の右上「管理画面」ボタン(管理者のみ表示)。タブ: **アセット / キャラ紐付け / ユーザ管理**。

## 3. アセット管理(キャラグラ / マップチップ)

### キャラグラのアップロード
- 「アセット」タブ → 「キャラグラ」→ グラ名 + 画像ファイルを指定してアップロード。
- **寸法は 96×160 固定**。不一致はアップロード拒否(エラー表示)。
- 透過色は teal(RGB 0,128,128)。アップロード時に透過処理される。
- グラ名 = 配信ファイル名(小文字化)。ゲーム内では `gra` 名やキャラ名紐付け(後述)で参照される。
- **同名は拒否**(既存の上書き事故防止)。差し替えるときは一旦削除してから再アップロード。

### マップチップのアップロード
- 「アセット」タブ → 「マップチップ」→ mapset 名 + 画像ファイルを指定。
- **入力は 1024×96 の左右分割**(左=画像 / 右=マスク)。これを 512×96 の透過PNG へ変換して保存する。
- 入力寸法が 1024×96 でない場合は拒否。
- mapset 名 = 配信ファイル名(小文字化)。マップの mapset に対応する。
- **同名は拒否**。差し替えは削除 → 再アップロード。

### 一覧・プレビュー・削除
- 各アセットはサムネイル + 寸法を一覧表示。
- **「同梱」バッジ付き(リポジトリ同梱の初期アセット)は削除不可**(削除ボタンは無効、サーバも 403 で拒否)。
- アップロードしたアセットは削除可能(確認ダイアログあり)。

## 4. キャラ名とキャラグラの紐付け

- 「キャラ紐付け」タブ。キャラ名/カテゴリ(key)→ グラ名 の対応(Index)を **登録・編集・削除**。
- グラ名はアセット一覧から候補補完される。
- ゲーム内でキャラの専用グラが見つからない場合、この紐付け → フォールバックの順で解決される。

## 5. ユーザ管理

- 「ユーザ管理」タブ。アカウント一覧(権限・キャラ数・作成日時)。
- **管理者付与/剥奪**、**パスワード強制変更**(管理者が新パスワードを直接設定)、**アカウント削除**(キャラも連鎖削除)。
- 強制パスワード変更・削除・管理者剥奪を行うと、対象ユーザの既存ログインセッションは失効する(再ログインが必要)。
- 安全弁(ロックアウト防止):
  - 自分自身の管理者剥奪・削除は不可。
  - 最後の管理者の剥奪・削除は不可。

## 6. アップロードしてはいけない画像

以下は **アップロード禁止**。

1. **PCGL 設定前のキャラグラ**
   PCGL が設定される前のキャラグラには、RPGツクール等のデータを複製していたプレイヤーがいた経緯がある。著作権上の問題があるため **原則禁止** とする。PCGL 準拠の正規アセットのみを使用すること。
2. **公序良俗に反するファイル**
   公序良俗に反する画像は禁止。

> 不適切なアセットを発見した場合は、アセット管理画面から該当アセットを削除すること(同梱 seed は削除不可のため、問題があれば選別除外の運用で対応)。
